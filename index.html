随机图片 API

简单、快速、免费的随机图片服务。根据设备方向与深色/浅色主题自动挑选，支持 302 重定向与 JSON 两种返回方式。

API 接口

URL 说明 返回
/pic 自动根据设备选择方向 302 重定向
/pic?img=ua 根据 User-Agent 判断方向 302 重定向
/pic?img=h 横屏随机图片 302 重定向
/pic?img=v 竖屏随机图片 302 重定向
/pic?json=h 横屏随机图片（含主题信息） JSON
/pic?json=v 竖屏随机图片（含主题信息） JSON

快速使用

📷 直接获取图片（适用于 img 标签、CSS 背景）

📊 获取 JSON 数据（包含主题信息）

// JSON 响应示例
{
  "theme": "dark",
  "url": ""
}

使用示例

HTML

<img src="/pic?img=h" alt="随机壁纸">

CSS 背景

body {
  background-image: url('/pic');
  background-size: cover;
}

JavaScript

fetch('/pic?json=h')
  .then(res => res.json())
  .then(data => console.log(data.theme, data.url));
💡 图片格式：WebP · 自动适配深色 / 浅色主题
